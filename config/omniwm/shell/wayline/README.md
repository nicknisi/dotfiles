# Wayline

A structured bar with labeled workspaces and quick status controls.

## Previews

![Wayline on the desktop](previews/desktop.jpg)

## What it changes

A 40 pt bar with coloured icon blocks, compact numbered workspaces and matching popouts. The bar starts across the top and supports all four edges; its contents scale with the thickness setting.

## Controls and commands

Use the bar buttons for media, audio, calendar and system controls. Change placement, thickness and widget options in **Settings > Styles & Widgets**.
