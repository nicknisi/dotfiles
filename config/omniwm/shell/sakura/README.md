# Sakura

A light bar with soft pink accents and a drifting-petal shader.

## Previews

![Sakura on the desktop](previews/desktop.jpg)

## What it changes

Sakura Glass: warm ivory, rose accents, rounded cards and falling cherry-blossom petals. The effect stays inside the bar and matching popouts. Its palette stays light in both system appearances.

## Controls and commands

Widgets keep their media, audio, calendar, weather and system controls. Adjust Sakura Petals under **Settings > Styles & Widgets > Bar**; the effect supports a still frame as well as animation.
