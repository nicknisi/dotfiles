# Matrix

A terminal-inspired bar with green accents and a rain shader.

## Previews

![Matrix on the desktop](previews/desktop.jpg)

## What it changes

Rain Terminal: a dark green, monospace style with falling code behind the full-width bar, compact numbered workspaces and square popouts. Its palette stays dark in both system appearances.

## Controls and commands

Widgets keep their media transport, volume, calendar, weather and system controls. Adjust Matrix Rain under **Settings > Styles & Widgets > Bar**; the effect supports a still frame as well as animation.
